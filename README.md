# Real-Time 3D Particle System using OpenGL

This project is a real-time 3D particle simulation developed using C++ and OpenGL. It explores particle motion, visual effects, and interactive 3D rendering.

## Features

- Real-time 3D particle simulation.
- Particle motion and visual effects.
- Interactive controls.
- Camera navigation.
- C++ and OpenGL graphics programming.

## Technologies Used

- C++
- OpenGL
- Visual Studio

## Getting Started

### Requirements

- Windows
- Visual Studio with the C++ development workload
- The OpenGL dependencies required by the project

### Run the Project

1. Clone or download this repository.
2. Open `ConsoleApplication2.sln` in Visual Studio.
3. Make sure the required OpenGL dependencies and project settings are configured.
4. Build the solution.
5. Run the application.

If the project does not build immediately, check the compiler settings and required library paths in the project configuration.

## Purpose

This project was developed to practice 3D graphics programming, particle simulation, and interactive rendering with OpenGL.
